بطاقتي في Wallet

بطاقة تعريف تفتحها في أي شركة، وفيها رمز QR يحفظ بياناتك في جوال الموظف.

١ شهادة Apple (مرة وحدة)
  1. نزّل pass.csr

    بعدها نزّل ملف pass.csr واحفظه في «الملفات».

  2. افتح تسجيل Pass Type ID: الوصف Wallet Card والمعرّف pass.sa.mudhaker.card ← Continue ← Register.
  3. افتح إنشاء شهادة: اختر Pass Type ID Certificate ← اختر المعرّف ← ارفع pass.csr ← Download.
  4. اختر الشهادة pass.cer
  5. نزّل شهادة Apple WWDR ثم:
    اختر AppleWWDRCAG4.cer

استرجاع نسخة

الشهادة ومفتاحها يبقون في متصفح جوالك فقط، ولا يرسلون لأي مكان.
