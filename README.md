# مذاكر 📚

رفيقك الجامعي للتنظيم والمذاكرة والتفوّق — تطبيق عربي لـ iOS وAndroid يخدم الطالب وعضو هيئة التدريس.

## المزايا

- **الرئيسية:** تقدم مذاكرة اليوم، الأيام المتتالية، المحاضرة الحالية والتالية، والمواعيد القادمة.
- **الجدول الأسبوعي:** محاضرات ومعامل وساعات مكتبية، مع تنبيه عند تعارض المواعيد.
- **المهام:** واجبات واختبارات ومشاريع (وتصحيح للدكتور) مرتبة: متأخرة / اليوم / هذا الأسبوع / لاحقاً.
- **ذاكر:** مؤقت بومودورو يسجّل وقت المذاكرة لكل مقرر.
- **بطاقات المراجعة / بنك الأسئلة:** تكرار متباعد بنظام صناديق لايتنر.
- **حاسبة المعدل:** نظام 5 أو 4 نقاط، معدل فصلي وتراكمي، وحساب المعدل المطلوب للوصول لهدفك.
- **استيراد الجدول:** انسخ جدولك من بوابة الجامعة أو Excel والصقه.
- **خلفية الجدول:** جدولك أو ساعاتك المكتبية كخلفية لشاشة القفل.
- **التحضير بالـ QR:** الدكتور يعرض رمزاً يتجدد كل 15 ثانية والطلاب يحضّرون أنفسهم، ويُسجَّل الحضور والغياب تلقائياً.
- **قناة الشعبة:** الدكتور ينشر شعبته برمز، فينضم الطالب وتُضاف عنده المادة بمحاضراتها واختباراتها، وتصله الإعلانات وأي تأجيل تلقائياً.
- **شارك نتيجتك و«ملخص فصلك»:** بطاقات ستوري للنتائج وملخص للفصل على طريقة Wrapped.
- **مواعيد Blackboard:** رابط التقويم الخاص بالطالب يُدخل الواجبات والاختبارات في المهام ويتحدّث تلقائياً (بلا كلمة مرور).
- **إشعارات فورية** لإعلانات الدكتور، و**قفل التطبيق بالبصمة**.
- **حجز الساعات المكتبية:** الدكتور ينشر ساعاته برمز، والطلاب يحجزون مواعيدهم ويصلهم تذكير.
- **لعضو هيئة التدريس:** الشعب، قوائم الطلاب (استيراد من Excel)، التحضير، كشف الغياب والحرمان، رصد الدرجات والتقديرات (تصدير Excel)، المجموعات والاختيار العشوائي، مراسلة الشعبة.
- **خطة مراجعة تلقائية** قبل كل اختبار وعدّاد للأيام المتبقية.
- **مشاركة الجدول** مع زميل كنص يلصقه في التطبيق.
- **فصل جديد:** يعتمد معدل الفصل في التراكمي ويجهّز الجدول للفصل القادم.
- **الدرجات:** سجّل درجات كل مقرر واعرف كم تحتاج في النهائي لكل تقدير.
- **الغياب والحرمان:** سجّل غيابك لكل مقرر، ويحسب التطبيق المتبقي قبل حد الـ 25% وينبهك عند الاقتراب.
- **نسخ احتياطي:** صدّر بياناتك واستعدها على جوال جديد.
- **التذكيرات:** قبل المحاضرة، ومساء اليوم السابق للتسليم وصباحه، وقبل الاختبار بثلاثة أيام (تعمل على الجهاز بدون إنترنت).
- **الإحصائيات:** رسم أسبوعي وتوزيع المذاكرة على المقررات.
- **مذاكر برو:** اشتراك شهري/فصلي/سنوي، ودفع بـ Apple Pay وGoogle Pay ومدى والبطاقات وSTC Pay.
- عربي بالكامل من اليمين لليسار، وضع فاتح وداكن، ألوان تحقق معيار التباين WCAG AA، وقراءة الشاشة (Accessibility).

## التشغيل

```bash
npm install
npx expo start        # امسح الرمز بتطبيق Expo Go على جوالك
```

أوامر الجودة:

```bash
npm run typecheck     # فحص الأنواع
npm run lint          # ESLint
npm test              # 129 اختباراً للتطبيق
./scripts/test-db.sh  # اختبارات قاعدة البيانات والصلاحيات (Postgres محلي)
```

> ملاحظة: عند أول تشغيل في Expo Go قد يلزم إغلاق التطبيق وفتحه مرة واحدة لتفعيل الاتجاه من اليمين لليسار. في النسخة المبنية يُفعَّل تلقائياً.

## البناء والنشر

```bash
npx eas-cli@latest build --platform all --profile preview      # نسخة تجريبية
npx eas-cli@latest build --platform all --profile production   # نسخة المتجر
```

## الدفع التجريبي

الدفع حالياً في **وضع تجريبي** لا يخصم أي مبالغ:

| الوسيلة | بيانات التجربة |
|---|---|
| بطاقة ائتمانية | `4111 1111 1111 1111` — أي تاريخ مستقبلي وأي CVV |
| مدى | `4406 4700 0000 0007` |
| بطاقة مرفوضة | `4000 0000 0000 0002` |
| STC Pay | أي رقم يبدأ بـ 05 ورمز التحقق `123456` |

انظر [PLAN.md](PLAN.md) لخطة الإصدار، و[AUDIT.md](AUDIT.md) لتقرير الفحص، و[marketing/](marketing/MARKETING.md) لخطة التسويق، و[LAUNCH.md](LAUNCH.md) لخطوات النشر، و[store/listing.md](store/listing.md) لبيانات المتجر.

عند إضافة مفاتيح RevenueCat (انظر `.env.example`) يتحول الدفع تلقائياً إلى اشتراكات App Store وGoogle Play الحقيقية.

## البنية

```
src/
  app/          الشاشات (Expo Router)
  components/   مكونات الواجهة
  lib/          المنطق: المعدل، الدفع، التواريخ، التكرار المتباعد، الإحصائيات (+ الاختبارات)
  store/        الحالة والتخزين المحلي
  content/      بيانات التواصل ونص سياسة الخصوصية والشروط
  lib/cloud/    الخادم: Supabase أو وضع تجريبي على الجهاز
supabase/       قاعدة البيانات (الهجرة + قواعد الأمان RLS + الاختبارات)
docs/           موقع الخصوصية والدعم (GitHub Pages) — يُولَّد بـ npm run docs
store/          صور المتجر ونص الوصف
  theme/        الألوان والخطوط والمسافات
```
